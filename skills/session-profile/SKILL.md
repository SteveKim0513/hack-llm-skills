# session-profile: AI와 일하는 실력 평가

사용자가 AI에게 보낸 요청은 세 종류다. **지시**(자기 말로 정함), **질문**(이해하려고 물음), **진행**(판단을 더하지 않고 넘어감). 지시와 질문은 기록에 남은 글로 평가한다. 진행은 기록만으로는 이해했는지 알 수 없으니, 몇 개를 골라 "지금 그건 어떻게 동작하나요?" 같은 서술형 질문으로 확인하고 그 점수로 진행 전체를 어림한다. 종합 점수는 세 종류의 품질을 대화에서 차지한 비율로 가중 평균한 것이다. 여기에 읽기 과제 하나를 더한다. 지어낸 AI 답변을 읽고, 지문이 사라진 뒤 답장과 동료에게 전하는 글을 쓰게 해 문해력을 따로 확인한다.

분류, 기준, 점수 기준, 일꾼 지시문은 모두 `references/rubric.md`에 있다. 쓰는 사람마다 결과가 달라지지 않도록 그 파일의 기준만 쓰고, 계산은 스크립트가 한다. 기록 형식은 `references/claude.md`, `references/codex.md`.

## 원칙
- 사용자가 하는 일은 확인 질문과 읽기 과제에 답하는 것뿐이다. 분류나 채점을 확인받지 않는다.
- 질문에는 무엇을 재는지 쓰지 않는다. 사용자가 물으면 "지난 대화 내용을 지금 얼마나 아는지 보는 질문"이라고만 답한다.
- 채점하는 일꾼과 다시 채점하는 일꾼, 질문을 만드는 일꾼과 답을 채점하는 일꾼은 서로 다른 에이전트여야 한다. 그럴 수 없으면 결과에 "검증 안 됨"을 붙인다.
- 결과는 평가받는 사람에게만 준다. 다른 사람과 비교하는 점수가 아니고, 선발이나 인사 평가에 쓰지 않는다.
- 대화 원문이 든 파일은 공개 저장소 밖(`~/.criteria/audit/`, 이하 `A`)에 둔다. 비밀번호나 키는 어디에도 옮기지 않는다. 저장소는 읽기만 한다.

## 순서
진행 중에는 단계를 한 줄씩만 알린다. 중간 결과는 보여 주지 않는다.

1. **모으기.** 최근 30일에서 세션 30개(진행 중인 대화는 뺀다).
   ```bash
   python3 scripts/extract_sessions.py --since <날짜> --sample 30 --max-chars 3000 --out A/sessions.jsonl
   ```
2. **분류와 채점.** `rubric.md`의 C대로 모든 사용자 요청을 분류하고 채점해 `A/turns.jsonl`에 쓴다. 세션이 많으면 일꾼 여럿에게 나눈다. 그다음 질문 후보와 다시 채점할 세션을 고른다.
   ```bash
   python3 scripts/quiz.py pick --sessions A/sessions.jsonl --turns A/turns.jsonl --out A/picked.json
   ```
3. **다시 채점과 질문 만들기 (동시에).** R대로 다른 일꾼이 고른 세션을 처음부터 다시 채점해 `A/recheck.jsonl`에 쓴다. Q대로 또 다른 일꾼이 확인 질문(정답을 확정할 수 있는 것만, 8개까지)을, T대로 읽기 과제 1~2개를 만들어 `A/quiz.json`에 함께 쓴다. 읽기 과제를 가운데쯤에 섞는다.
4. **답하기 (사용자).** 화면을 열어 주고 "다 풀면 제출을 눌러 주세요" 한 줄만 쓴다.
   ```bash
   python3 scripts/quiz.py serve --quiz A/quiz.json --answers A/answers.json
   ```
   127.0.0.1에서만 열린다. 정답은 화면으로 나가지 않는다. 읽기 과제는 "다 읽었어요"를 누르면 지문이 사라진다.
5. **답 채점.** 제출되면 G대로 Q와 다른 일꾼이 `A/answers.json`을 채점해 `A/graded.json`에 쓴다.
6. **결과.**
   ```bash
   python3 scripts/score.py --sessions A/sessions.jsonl --turns A/turns.jsonl --turns-b A/recheck.jsonl \
     --graded A/graded.json --out A/report-<날짜>.html
   ```
   파일을 열고, 대화에는 종합 점수, 가장 낮은 기준, 파일 위치만 쓴다.
7. **정리.** 중간 파일을 지울지 묻는다.

## 한계
- 채점은 AI의 판단이다. 다시 채점한 일꾼과의 일치를 결과에 적고, 낮으면 경고한다.
- 진행 요청의 점수는 고른 몇 개의 확인 질문으로 전체를 어림한 것이다.
- 기록 밖에서 한 일(머릿속 판단, 화면에서 직접 확인)은 보이지 않는다.
- 이 구성으로 실제 사람에게 끝까지 돌려 본 적은 없다. Codex 기록으로도 확인하지 못했다.
