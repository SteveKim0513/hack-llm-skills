# 검증 기록

이 스킬의 기본값을 정할 때 실제로 확인한 것. 모두 **사용자 한 명, 세션 25개 표본**에서 나왔다. 다른 사람의 기록에서는 다를 수 있으니, 처음 쓰는 사람은 4단계에서 자기 표본으로 다시 확인한다.

## 1. "받아들였다"는 로그로 판정되지 않았다 (2026-10-22)
- AI가 "세부 없이 수용"으로 분류한 장면 14건을 사용자가 확인: **맞음 0, 아님 11, 애매 3.**
- "아님" 이유: 승인 앞뒤의 질문으로 이해를 보였다, 의도(도구·대상·깊이)를 직접 정했다, 이슈를 닫고 다음 문제를 찾으려는 말이었다, 짧은 진행 신호였다(7건).
- "애매" 이유: 이해 여부를 확인할 수 없다(3건).
- AI가 "한 행동(능동)"으로 분류한 장면은 6건 중 5건이 맞았다. 표본이 작아 참고용이다.
- 결론: 있었던 행동만 세고, 승인은 세지 않는다.

## 2. 세션 비율은 쉽게 포화된다
- 25개 세션에서 구조 96%, 방향 주도 92%, 검증 88%, 메타인지 72%의 세션에 행동이 있었다.
- 원인 하나는 장면 찾기 지시에 "네 축을 모두 채우려고 하라"는 문장이 있었던 것이다. 이 지시는 SKILL.md에서 금지했다. 지시를 빼면 비율이 내려갈 것으로 보이지만 다시 측정하지는 않았다.

## 3. 장면 수는 대화 길이를 따라간다
상한(15건)에 걸린 8개를 뺀 17개 세션에서, 사용자 발화 수와 행동별 장면 수의 순위 상관(스피어만):

| 행동 | 장면 수 vs 길이 | 10발화당 vs 길이 |
|---|---|---|
| 검증 | +0.61 | -0.21 |
| 구조 | +0.14 | -0.54 |
| 방향 주도 | +0.62 | -0.15 |
| 메타인지 | +0.60 | +0.33 |

- 검증과 방향 주도는 10발화당으로 바꾸면 길이 영향이 대부분 사라졌다. 세션을 합친 비율은 발화 10개 미만과 10~29개에서 각각 2.6과 2.0(검증), 2.1과 2.0(방향 주도)이었다.
- 구조는 장면의 52%가 대화 시작이나 새 방향에서 나와, 긴 대화일수록 발화당 비율이 낮아졌다(2.6에서 1.1). 메타인지도 50%가 앞쪽이었다. 그래서 이런 행동은 "응답 중 장면만" 비율을 따로 본다.
- 발화 6개 미만 세션은 장면 1건만 나와도 10발화당 2.0~3.3이 되어 잡음이 크다. 그래서 세션별 분포에는 발화 10개 이상 세션만 넣고, 전체 비율은 세션을 합쳐 계산한다.
- 발화 30개 이상 세션은 모두 상한에 걸려 비율 계산에서 빠졌다. 긴 대화에 대한 비율은 아직 확인하지 못했다.

## 4. 아직 확인하지 못한 것
- 다른 사람의 기록, 다른 언어
- "네 축을 채우라"는 지시를 뺀 뒤의 세션 비율
- 사용자 확인 기반의 AI 분류 일치율(6단계)
- 유형 나누기(8단계)
