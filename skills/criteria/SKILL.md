# criteria: 기준 기록소

사용자가 확정한 판단 기준을 파일로 남겨, 같은 질문을 반복하지 않고 답변에 반영하게 한다.
저장 형식은 `references/format.md`를 따른다. 먼저 읽는다.

## 하는 일
- **목록**: `INDEX.md`를 읽어 영역별로 보여준다. 상태(확정/초안/대체됨/폐기)를 같이 표시한다.
- **보기**: 기준 파일 하나를 보여준다. 대체 이력이 있으면 이전 버전 링크도 보여준다.
- **추가**: 사용자가 말한 기준을 그대로 적는다. 출처는 `user`.
- **변경**: 기존 파일을 덮어쓰지 않는다. 새 버전 파일을 만들고 `supersedes`로 연결하고 이전 파일은 `superseded`로 바꾼다.
- **확정**: 초안을 사용자가 승인하면 `confirmed`와 `confirmed_at`을 기록한다.
- **폐기**: 상태를 `retired`로 바꾼다. 파일은 지우지 않는다.

## 지켜야 할 규칙
- **사용자가 확정한 기준만 `confirmed`가 된다.** AI가 추정했거나 같이 만든 기준은 `draft`로 저장하고, 사용자의 명시적 동의 뒤에만 올린다.
- 기준 본문은 사용자의 표현을 최대한 그대로 둔다. 요약하며 의미를 바꾸지 않는다.
- 파일을 바꿀 때마다 `INDEX.md`를 같이 갱신한다.
- 같은 영역·결정 종류에 `confirmed`가 이미 있는데 새로 추가하라고 하면, 변경으로 처리할지 묻는다.

## 관리 화면 (로컬 웹)
기준을 쓰거나 고칠 때는 대화 대신 로컬 웹을 쓴다. 대화 흐름이 끊기지 않고, 목록·이력·후보 선택을 한 화면에서 할 수 있다.
사용자가 "기준 열어줘", "기준 바꿔줘"라고 하거나 다른 스킬이 기준 작성을 요청할 때 연다.

**실행.** 이 스킬 폴더의 `scripts/start.sh`를 백그라운드로 실행한다. python3 3.8 이상만 있으면 되고 설치할 패키지는 없다.
- 관리 모드(보기·수정): `scripts/start.sh --dir <프로젝트>/.criteria`
- 대기 모드(작성이 끝날 때까지 기다림): 위에 `--wait --context "지금 하던 일"`을 더한다. 필요하면 `--area`, `--decision`으로 폼을 미리 채우고, 사용자가 "모름"일 때 고를 후보를 `--candidates <JSON 파일>`(`[{"title","body"}]`, 최대 6개)로 넘긴다.
- `--timeout`은 대기 모드에서 총 대기 초(기본 900), 관리 모드에서 유휴 초(기본 3600).

**결과 읽기.**
- 출력 첫 줄의 JSON `url`을 사용자에게 보여준다. 브라우저가 자동으로 열리지 않을 수 있다.
- 종료하면 마지막 줄에 `{"result": ..., "saved": [...]}`가 나온다. 같은 내용이 대기 모드에서는 `<dir>/.last-action.json`에도 남는다.
- `result`: `saved`(저장하고 완료), `closed`(저장 없이 닫음), `proceed`(사용자가 "일단 진행" 선택), `timeout`(응답 없음). 종료 코드는 각각 0, 0, 3, 2.
- 웹에서 저장한 기준은 이미 파일에 기록되어 있다. 다시 쓰지 말고 읽어서 쓴다.

**쓸 수 없을 때.** 원격 환경이라 주소를 열 수 없거나, python3가 없거나, 실행이 실패하면 대화로 같은 질문을 한다. 한 번에 하나만 묻고, "모름"이면 후보를 보여준다. 이 경우에도 저장은 이 스킬의 규칙을 따른다.

**주의.** 서버는 내 컴퓨터(127.0.0.1)에서만 열리고 주소의 토큰이 열쇠다. 토큰이 든 주소를 다른 곳에 공유하지 않는다. 대기 모드는 프로젝트 `.criteria/` 안에 `.last-action.json`을 만들므로, 프로젝트가 git이라면 `.criteria/`를 `.gitignore`에 넣을지 사용자에게 알린다.

## 저장 위치
- 프로젝트: 작업 폴더의 `.criteria/` (기본값)
- 전역: `~/.criteria/` (여러 프로젝트에 공통인 개인 취향)
- 같은 영역·결정 종류가 양쪽에 있으면 프로젝트 쪽이 우선한다.
- 위치를 사용자가 명시하지 않았으면 기본값에 저장하고, 어디에 저장했는지 한 줄로 알린다.
